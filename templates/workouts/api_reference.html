API reference

The read-only API is served at /api/v1/. Create a named token on the Tokens screen and send it on every request: 

Authorization: Bearer <secret>

Data is scoped to the token's owner. Responses carry contract_version and generated_at, and errors use {"error": {"code", "message", "details"}}. The anonymous liveness probe is {{ api_health_url }}; every other endpoint requires the bearer token.

Machine-readable schema

The generated OpenAPI schema is at {{ api_schema_url }}. Browser navigation sends no bearer token, so opening it directly returns 401; fetch it with the token instead. The full endpoint-by-endpoint contract is in the repository's docs/api.md.
